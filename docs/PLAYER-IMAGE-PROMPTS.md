# Player image prompts (manual generation via ChatGPT Pro web)

These 10 silhouette images are consumed by the crowdaq xibo-plugin widget. Each fires on a specific game event (goal celebration, yellow card frustration, etc).

## Workflow

1. Open ChatGPT (Pro account, image gen included)
2. Copy each prompt below verbatim into a new chat
3. After ChatGPT generates the image, click the download icon
4. Save the PNG to: `xibo-plugin/modules/assets/players/argentina-10-<slug>.png`
   (slug listed for each prompt below)
5. Verify before saving: black silhouette only (no real face), generic light blue + white vertical stripes (no AFA sun / Adidas / sponsors), `10` on jersey back
6. Once all 10 saved: tell coordinator. Agent will commit + deploy.

## Legal / visual constraints baked into every prompt

- Body, head, hair, arms, legs are pure black silhouette — no faces, no skin features, no real-player likeness
- No team logos, sponsor patches, or registered trademarks (NO AFA sun, NO Adidas stripes, NO sponsor crest)
- Generic light blue + white vertical stripes only (Argentina kit visual style, NOT actual licensed kit)
- Number `10` on jersey back in white
- Plain dark shorts, no logo
- Dramatic stadium-lit cinematic lighting, backlight halo so silhouette pops
- Vertical aspect 4:5 (1024 x 1280 PNG)
