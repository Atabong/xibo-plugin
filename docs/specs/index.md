## Cross-repo context

All 16 specs target a new `modules/widget-v2/` subtree, side-by-side with the existing v1 `modules/crowdaq-widget.xml`. The v1 widget is untouched by these specs — v2 ships as a new XML manifest declaring a new `<type>crowdaq-widget-v2</type>`, mounted by Xibo as a separate widget. The v1/v2 transition is operator-driven via the Xibo layout authoring surface (chaos vector #3 in `system-architecture.md`).

Cross-repo dependencies (`SPEC-CRWDQ-013`, `017`, `026`, `030`, `033`, `026`) live in `crowdaq-backend/docs/specs/` (branch `docs/specs-backend`). The xibo-plugin specs assume those interfaces stable.

## Common vocabulary

Shared protocol terminology lives in `xibo/docs/specs/SPEC-CATALOG.md` "Common vocabulary" section. Each spec references the relevant D-GRH-NN decisions for player-runtime contracts — they are NOT re-derived per spec.
